# デザインの決まり

ユーザーと決めた、サイト全体にかかわる見た目と見せ方の決まり。画面を変える・足すときは先に読む。ページごとの並びや部品の形はコードとそのコメントにある。

## 1. 方針

- **県を批判するためではなく、状況を公平に確かめるためのサイト。** 順調・遅れのどちらかだけを目立たせない（遅れの件数を大きく並べる・悪い順に並べる・良いものだけに絞ったリンクを置く、はしない）。全体の内訳を同じ重みで見せ、遅れ・後退は一覧の絞り込み（`?pat=delay3`・`?trend=down` など）で見られるようにする。並びは報告書の順。前の年度からの変化は、良くなったものと悪くなったものを対にする。
- **計画は3つの段で見せる。** 基本施策と主要指標（沖縄の姿）、施策と成果指標（施策の成果）、主な取組と活動指標（県の活動）。将来像は段ではなく、基本施策を束ねる枠。
  - 同じ段のものと物差しはいつも一緒に見せ、段をまたぐつながりはページの移り（ページの階層・子の一覧）で見せる。
  - 物差しどうしを縦に結ぶ図（成果指標が上がると主要指標が上がる、のような）は、県が決めていない結び付きになるので作らない。
  - 段ごとに物差しが違う（主要指標は R9 の目標値に、成果指標と取組はその年度の計画に対して）ので、1つの図・目盛り・凡例の表にまとめず、段どうしの差も書かない。
  - 3つの段を一度に並べるのは、トップと将来像のページの頭（`Ladder`）と指標のマップだけ。くらしのテーマのページの頭は、テーマと主要指標の対応を決めていないので2段。
- 状態の言葉は県の区分のまま使う。活動指標の数は「計画 10件 → 実績 54件」と書く（「目標」は成果指標の目標値と取り違える。100%以上は「計画クリア」）。県の資料の「再掲」は「共通」と言う。
- 情報は減らさず「ひとめで → くわしく → 表と原文は畳む（`details`）」の順にする。図には「表で見る」を付ける。行ごとに細い棒を並べる所・ページの頭の段・指標のマップは表を置かず、値はツールチップ・吹き出し・読み上げで出す。
- 区分の内訳は、数えられるほど少ないもの（20個ほどまで）は1件1つのマス（`StatusBar` の `cells`・`squares`）にし、多いものと行どうしで割合を比べるものはつながった棒にする。
- 凡例は、同じ区分の図を並べるときも1回だけ。行ごとに棒やハンコを並べる所は凡例の箱を置かず、行の「順調」「判定」などを押すと区分を出す（`KeyBrief`・`JudgeLegend`）。
- 節の頭の文は、表示や操作の説明（「棒は〜」「押すと〜」）にせず、何が載っていて何が分かるか（見る人の問い・だれが決めたものか）を1文で書く。データの注意書きは図や表の後ろに、年度のつなぎ方（前の年度の名前など）はページの出典に書く。
- 用語は `Term` で説明し、本文で繰り返さない。

## 2. 見た目

- 太い線と硬い影の「ステッカー」を並べるポップな見た目。色・リンク・書体・印刷の決まりは `styles/global.css` のトークンとコメントにある。はじめは端末の設定に関係なくライトで表示し、ダークはフッターのボタンで選んだときだけ。
- ステッカーの強さは3段階: 太い線と大きな影（`.sticker.lift`）はページの頭とトップのヒーローだけ、並ぶカード・図・絞り込みは `.sticker`、ステッカーの中の箱は線も影も無い地の色だけ（`.inset`）。ステッカーの中の吹き出しやステッカーには影を付けない。
- 状態（順調〜大幅遅れ、判定 A〜G）は色に加えて形と文字で出す（`lib/icons.ts` の `Icon`・`Chip`）。地との差が 3:1 未満の色は、形と棒の区間に縁を付ける（`--*-edge`）。
  - 例外: 指標のマップのマスは色だけ（数が多い）。凡例と吹き出しで区分の言葉を出す。
  - 例外: 主要指標の札は形を付けず、県の概要版の区分の言葉と数（「後退 -6%」）にする（`ShuyouTags`。形にすると「前進（60%未満）」が「やや遅れ」と同じ▲になる）。
- 丸いハンコは施策の判定だけに使う。取組の進捗状況は横長の札と4年分のスタンプ。
- 色の役割を混ぜない。状態の色、将来像の色（`--sz-1`〜`--sz-5`。番号の印と帯だけ）、札の地の色（くらしのテーマはピンク、個別計画は淡い紫、一括交付金は砂色、年度の札は薄い青）は、それぞれほかの意味に使わない。
- 年は報告書と同じ和暦。文章（節の頭の文・注記・見出し・畳んだ内容の見出し）では「令和7年度」、表・図・札・絞り込みの選択肢・数字の並びでは「R7」と書く（`yearLong`・`yearsLong` と `yearLabel`）。県の資料から写した文と PDF の名前は印字のまま。フッターのボタンで西暦に切り替えられるが、変えるのは画面の文字と読み上げだけで、外のサイトへのリンクの文字・ページの説明文・SNS のカード・HTML は和暦のまま（`lib/era.ts`）。

## 3. 一覧・番号・リンク

- 一覧は1つの箱の中に細い線で区切った行で並べる（`.row-list`）。1件は2〜3行に収め、一覧の見出しにあること（将来像・基本施策）は行に書かない。
- 絞り込みの条件は URL のクエリに残し、一覧の上に × で外せる条件を並べる。キーワード以外の条件は `FilterMore` で畳む。指標のマップは、条件に合わないマスを隠さずに薄くする。長い一覧は「さらに表示（残り N件）」で残りを全部出す。
- 報告書の番号（`1-(1)-ア-①`）は名前より目立たせず、小さく薄い字にする（`.code-no`）。ページの題名は名前だけにし、番号でも検索できるようにする。計画の目次とページの階層は、通しの番号ではなく階層の中の番号を名前の頭に置く。
- 節の見出しは、どのページもその節の # へのリンクにする（`SecHead`）。リンクの中にボタンは入れられないので、見出しに `Term` を入れず、用語は節の頭の文で説明する。同じ役目の節は、ページが違っても # の名前をそろえる（`judge`・`trend`・`list`・`yosan`・`source` など）。

## 4. ページの組み立て

- ページの頭: 1つのものを見せるページは `.sticker.lift.page-head` に、区分と番号の行（`HeadKind`。くらしのテーマは右端）→ 題名 → 補足の行（`.head-meta`）→ いまの状態の箱（`.head-box`）→ 県の吹き出しの順。将来像・くらしのテーマは印のある頭（`.badge-head`）。一覧・さがす・読み物のページはステッカーにせず、h1 と `.lead`（一覧は `.secondary`）。
- 吹き出しは `Says`: 県の資料の言葉は「県」、このサイトからの注意は「!」。
- ヘッダーのナビはサブメニューを使わず、計画の段の順に並べる（並びは `layouts/Base.astro` の `NAV`）。タイトルの横に最新の対象年度の版（「令和7年度版」）を出す。
- 1つのものを見せるページには、頭のすぐ後にページ内の目次（`Toc`）を置いて上に固定する。貼り付いたら何のページかを1行で出す（本文はずらさない）。
- パンくずの代わりに、ページの頭の上にページの階層（`Hierarchy`）を置き、上の段だけを目次のように下げて線でつなぎ、最後の段から頭のステッカーへ線を伸ばす。上の階層の無いページ（将来像・ナビから入る一覧）と、くらしのテーマ・部局・観光ロードマップのトップには置かない。スマホの幅では、階層のあるページをリンクから開くとページの頭から始める。

## 5. 県の計画とは別のもの

- くらしのテーマは**このサイト独自の分類**で、県の計画の分類ではない。画面では必ずそうと分かるように出す（「このサイト独自の分類」の印・ピンクの札）。どの施策もいずれかのテーマに入るように `themes.json` を保つ。
- 個別計画（観光ロードマップ）と一括交付金の事後評価は、沖縄県PDCAとは別の計画・評価。施策・取組の一覧と件数に混ぜず、札の色で見分ける。一括交付金の事業は、名前が同じでも主な取組と結び付けない。個別計画はナビと5つの将来像のページに置かず、くらしのテーマ・関係する施策と取組のページ・フッターから入る。
- サイトの説明は3ページに分け、県の説明とこのサイトの読み方を混ぜない: 県が決めて公表していること（仕組み・計画の階層・物差し・用語）は沖縄県PDCAについて、このサイトが県の資料をどう読み・数えたかはデータについて、このサイトそのもの（なりたち・作り手・技術・ライセンス・デザイン・アクセシビリティ・運営）はこのサイトについて。用語の一覧も県の言葉だけにする（このサイトの言葉は `lib/terms.ts` の `OWN_TERMS`）。データについては数字を読むのに要ることだけを書き、例外の一覧は [data.md](data.md)・[issues.md](issues.md) に任せる。

## 6. 意見・シェア・いいね

- 1つのものを見せるページの終わり（出典の前）に、いいねとシェアの枠（`ShareBox`。言葉は「ページが役に立ったら」）を置く。指標はカードの右上の「シェア」で1つずつシェアできる（`ShareMenu`）。
- **いいねの件数は画面に出さない**（よく押された順という物差しができ、1章の「同じ重み」とぶつかる）。コメントの欄も置かない。
- SNS に書いても県には届かないことは `/iken/` で伝える。ハッシュタグ（`lib/iken.ts` の `HASHTAG`）は公開の場の X・Threads・Bluesky にだけ付ける。

## 7. サイトの名前と作り手

名前は「おきなわ、みらい、いま」（縮めて「みらいま」）。名前・略称・説明は `lib/links.ts` の `SITE`、作り手は `PROJECT`、ハッシュタグは `lib/iken.ts` の `HASHTAG` に1か所で決め、画面の文字もここから出す。

## 8. 動き

サイトを楽しく、分かりやすくするために動きを付ける。ただし、表示が遅くなる・ガタつく・読む手間が増える動きは付けない。

- **意味のある動きだけ。** 押した・変わったの手ごたえ、図を読む順（スタート → いま → ゴール）、どこからどこへ移ったか、の3つ。飾りだけの動き、ずっと動き続けるもの、数字のカウントアップ、スクロールに合わせて出す動き、パララックスは使わない。
- **例外は地の波だけ。** ページの地いっぱいに、淡い色の大きな波を重ねてゆっくり流し、呼吸のように少し上下させる（`.bg-waves`）。よく見ると動いていると分かるくらいの速さにとどめ、ずっと動き続けるのはこれだけにする。波は地より少しだけ濃い色にとどめ、上の縁は地に溶かして文字の行の後ろにくっきりした線を作らない。地の上の文字はどの波の上でも 4.5:1 以上にする。動きを減らす設定では止まった波を出し、印刷では出さない。
- **1回だけ短く。** ボタンや吹き出しは0.1〜0.25秒、図は0.8秒ほど。ページを移るときは重ねて切り替えない（`@view-transition` は使わない）。
- **見た目だけを動かす。** transform・opacity・clip-path・SVG の線の描き方だけを動かし、幅・高さ・位置は動かさない。
- **ふだんの見た目は動き終わった形。** キーフレームには始まりの形だけを書く。動きを減らす設定・印刷・対応していないブラウザでは、はじめから動き終わった形で見える。
- **状態の区分はどれも同じ動き。** 遅れだけを揺らす・順調だけを光らせる、はしない。一覧の行のように数の多いものは動かさない。
- 動きの見た目は `styles/global.css` の「動き」に、スクリプトから動かすものは `scripts/motion.ts` にまとめる。外のライブラリは足さない。

## 9. アクセシビリティ

目の見え方や使う道具（読み上げソフト・キーボードだけの操作・動きを減らす設定）にかかわらず、同じ内容に届くようにする。

- **値は必ず文字でも出す。** 図・色・ツールチップにしか無い値を作らない（「表で見る」・行の文・`aria-label` のどれかで読める）。ツールチップは補助で、読み上げソフトには出さない。
- **図は1つの画像として読み上げる。** 図の枠に `role="img"` と値をまとめた `aria-label` を付ける。年度ごとの値の図・指標のマップ・押せる四角・計画の目次の木は Tab で1回だけ止まり、矢印キーで移って中身を出し、Enter でそのページへ移る。キーで動かせることは止まったときに小さく出し（`.key-hint`）、`aria-label` の終わりにも書く。
- **同じことを2回読ませない。** 画面に見えている文字と同じ内容や、見た目だけの印は `aria-hidden` にする。
- **見た目で分かることは読み上げ用の文で補う**（`.sr-only`。行の値・スタンプの年度・表の `caption`・アイコンだけのボタンの名前・階層の段の名前など）。
- **キーボードで使える。** 全ページの先頭に「本文へスキップ」を置き、フォーカスは `:focus-visible` の太い枠で示して消さない。貼り付いた目次の下にフォーカスが隠れないよう上を空ける。押したボタンが消えるときはフォーカスを続きへ移す。押せる選択肢は本物の radio・checkbox にする。吹き出しとツールチップは Esc で閉じる。
- **状態の変化は属性で伝える**（`aria-current`・`aria-expanded`・`aria-pressed`。画面にだけ出る知らせは `role="status"`、件数が変わる一覧は `aria-live`）。
- 色のコントラストの基準（WCAG）とウェブアクセシビリティの規格（JIS X 8341-3）に沿う。このサイトについてのページでも沿っていると書いているので、色やページの作りを変えるときに崩さない。
