# データの欠け・誤りの一覧

`python3 scripts/report_issues.py` で data/extracted から自動で作っている（2026-10-11 作成）。手で編集しない。原因を人が調べたものは scripts/report_issues.py の NOTES・KNOWN_GAPS・BUDGET_NOTES に書く。作り方の全体は [data.md](data.md)。

元の報告書: [沖縄県PDCA実施結果（年度別）](https://www.pref.okinawa.jp/kensei/shisaku/1014252/1014253/index.html)（総括報告書）、[沖縄県PDCA](https://www.pref.okinawa.jp/kensei/shisaku/1014252/index.html)の各部局のページ（主な取組検証票・成果指標検証票）。

- **A. 取れていないデータ**: 元のファイルが手に入らない、読み取れていない、報告書の欄が空欄のもの。
- **B. 誤りの疑いがあるデータ**: 報告書の値が、同じ報告の他の箇所や、概要版に書かれた計算式と合わないもの。県の報告書の誤記か、このプロジェクトの読み取りの誤りかは個別に確認が要る。どちらも元の報告書（各行の出典）で確かめること。
